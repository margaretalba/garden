#metalsmithing #GRS 

**Materials:**
- [QC Onglette](https://grs.com/product/qc-onglette/?attribute_size=QC-1+%E2%80%A2+1+%281.78+mm%29)
- [38 Flat](https://grs.com/product/qc-flat/)
- Brass wire for punch
- Copper wire

**Shaping the QC Onglette**

|     | Post | Tilt | Beg Grit | End Grit |
| --- | ---- | ---- | -------- | -------- |
| 1   | 55   | Face | 260      | Ceramic  |
| 2   |      |      |          |          |
| 3   |      |      |          |          |

**Shaping the 38 Flat**

|          | Post | Tilt | Beg Grit | End Grit |
| -------- | ---- | ---- | -------- | -------- |
| 1        | 45   | Face | 260      | 1200     |
| 2        | 2.5  | 0    | 260      |          |
| 3 - HEEL | 20   | 0    | 1200     | Ceramic  |

**Making the punch**

|          | Post | Tilt | Beg Grit | End Grit |
| -------- | ---- | ---- | -------- | -------- |
| 1        | 90   | 90   | 180      | 180      |

**To note**
   1. Graver is width of the wire
   2. Punch is twice the width of the wire
